# Viaje a Japón · Octubre 2026

Planificación del viaje de Jaime y Marina a Japón, del **3 al 17 de octubre de 2026**.

## Contenido de la carpeta

| Archivo | Qué es |
|---|---|
| `CLAUDE.md` | Contexto completo para Claude Code (léelo antes de nada si lo abres con Claude) |
| `README.md` | Este archivo |
| `itinerario.md` | Ruta día a día con transiciones |
| `pois.md` | Puntos de interés por ciudad |
| `reservas.md` | Estado de reservas y prioridades |
| `ruta_japon.html` | **Mapa interactivo — ábrelo en un navegador** |

## Uso rápido

**Ver el mapa:** abre `ruta_japon.html` en Chrome, Safari o Firefox.

**Retomar la planificación con Claude Code:**
1. Abre esta carpeta con Claude Code
2. Empieza pidiendo: "Lee CLAUDE.md y dime en qué estado está el viaje"
3. Claude tendrá todo el contexto y sabrás por dónde ibas

**Actualizar el mapa manualmente:** edita el array `stops` dentro del `<script>` en `ruta_japon.html`. Cada parada tiene su nombre, fechas, noches, coordenadas, notas y lista de POIs.

## Resumen del viaje

- 14 noches, 6 paradas (Tokio · Kawaguchiko · Kioto · Koyasan · Kanazawa · Tokio)
- Aterrizaje y salida por Narita
- Enfoque cultural: ryokan, shukubo, machiya donde tenga sentido
- Presupuesto: 90-150 €/noche para dos (con flexibilidad en experiencias especiales)
